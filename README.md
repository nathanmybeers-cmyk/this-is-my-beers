# This is My Beers

Mini-jeu web autour de l'univers My Beers : ouvre ton bar dans ta ville, aménage-le, recrute ton équipe et enchaîne les soirées au comptoir. Un mode Arcade permet de comparer qui sert le mieux.

**Jouer :** ouvrir `index.html` dans un navigateur (ordinateur ou téléphone). Aucun serveur ni installation n'est nécessaire.

- `index.html` : tout le jeu (HTML, CSS, JavaScript).
- `vendor/` : Three.js (vue 3D) et les polices Lilita One / Fredoka, en local pour fonctionner hors ligne.
- `supabase/` : schéma et guide pour activer les classements en ligne.

Partie de test avec de l'argent : `index.html?argent=100000` (sauvegarde séparée).
